# Hushtype 隐私说明

## 留在本机的
- **录音**：只在按住快捷键（或免提模式）期间录音；语音识别全部在本机完成，录音从不上传。
- **历史**：整理结果保存在 `~/Library/Application Support/Hushtype/History`，默认保留 30 天，可设为不保存。保存录音默认关闭。
- **API key / 令牌**：只存在 macOS 钥匙串里。

## 发送给整理服务的（关闭「离线」时）
- 识别出的文字（两份识别结果）。
- 可关闭：当前应用名、窗口标题、光标前后各约 1,500 字、选中的文字。用来判断专有名词写法和语气。
- **不会**读取或发送：整个屏幕的内容、截图、录音。
- 密码管理器（1Password、Bitwarden、钥匙串访问、密码 App 等）里永远不读取上下文；也可以在设置里排除其他 App。
- 「从你的修改中学习」：你改了插入的文字时，只把改动前后那一小段发给同一个整理服务，判断要不要记进词典。

## 整理服务发给谁
在「设置 › AI › 来源」里选择，发送的内容（上面这些）和保护措施对所有来源都一样：

| 来源 | 发往 | 谁的隐私政策 |
|---|---|---|
| 我的 Anthropic API key（默认） | `api.anthropic.com`（Claude Sonnet 5.5，可换 Haiku 5.5） | Anthropic |
| 其他模型服务商 | 你选的服务商：DeepSeek、智谱 GLM、月之暗面 Kimi、通义千问（阿里云百炼）、豆包（火山方舟）、OpenAI，或你自己填的 OpenAI 兼容地址 | **该服务商**（数据可能存储在中国大陆或其他地区，部分服务商可能用 API 数据改进模型，请先看它的条款） |
| Hushtype Cloud / 自建代理 | 代理地址，再由代理转给 Claude | 代理运营方 + Anthropic；**只支持 Claude** |
| 离线 | 不发送任何内容 | — |

所有来源共用的保护：
- **只走 https**：服务地址不是 `https://` 的一律拒绝；不跟随重定向（防止带着 key 被转到别的地址）。
- **发送前在本机隐去**：光标附近的密钥、密码、卡号、身份证号；网址只保留域名和路径。
- **防注入**：转写和屏幕文字一律当作资料，其中冒充 Hushtype 标签的内容会被替换成形似字符。
- **不让模型「思考」、不开工具调用**：每家都显式关闭推理模式；返回里如有 `<think>…</think>` 推理内容会被丢弃，只插入正文。
- **API key**：每个服务商一个，单独存在 macOS 钥匙串（`app.hushtype.Hushtype` / `llm-key.<服务商>`）；不写进设置文件、备份和日志；服务商报错信息里如果带出 key 也会先隐去。
- 导入别人的备份文件**不能**改你的整理服务、服务地址或模型。
